# SQL Projects

This folder contains SQL projects completed using PostgreSQL while learning data analysis with SQL. Each script explores a different business question using SQL techniques such as joins, common table expressions (CTEs), aggregate functions, and window functions.

## Project Files

| File | Description |
|------|-------------|
| `1_top_paying_jobs.sql` | Identifies the highest-paying data-related jobs. |
| `2_top_paying_jobs_skills.sql` | Analyzes the skills required for the highest-paying jobs. |
| `3_top_demanded_skills.sql` | Finds the most in-demand skills across job postings. |
| `4_top_paying_skills.sql` | Determines which skills are associated with the highest salaries. |
| `5_optimal_skills.sql` | Identifies skills that are both in high demand and well paid, making them valuable to learn. |

## Skills Demonstrated
